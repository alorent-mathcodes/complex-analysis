Read the notes

Opens the notes in your browser. 132 figures play as animations, right on the page.

How to use

  • Click (or tap) a figure with a ▶ button: it plays in place. Click again to pause.
  • On a computer, hover over a figure for more buttons: ⟲ from the start, ■ back to the printed figure, </> its Python code, and Py, which runs that code live in your browser instead of the recording (it needs the internet, and a few seconds to start).
  • Links in the notes work; ← Back returns to where you were.

Download

The PDF (7.0 MB)

For printing or any PDF viewer. In an ordinary PDF viewer the figures are still pictures; they move only in the reader above or in the offline copy.

Everything, for offline use (zip, 86.3 MB)

The notes with all the animations, working without internet on a computer. Unzip it, then double-click Open the notes.html.

Windows
Right-click the zip → Extract All…, then double-click Open the notes.html in the new folder.
Mac
Double-click the zip (a folder appears), then double-click Open the notes.html in it.
Linux
Right-click the zip → Extract Here, then double-click Open the notes.html.

Save for offline (phones and tablets; 88.0 MB)

Stores the notes, all the animations and the reader in this browser, so that Read the notes works without internet. On an iPhone or iPad, first add this page to your home screen (Share → Add to Home Screen), open it from there, and press the button there: Safari keeps the home-screen copy separately. On Android, Chrome's menu → Add to Home screen / Install app gives it an icon.
